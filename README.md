# 🫧 The Bubble Game

> **[🚀 View Live Demo](https://omniranjan.github.io/The-Bubble-Game/)**

A fun and interactive web-based game built with HTML, CSS, and JavaScript where players race against time to click the target matching bubble and score points!

## ✨ Features
- **Dynamic Bubble Generation:** Spawns multiple randomized bubbles on the screen with unique numbers.
- **Target Matching:** A target number is randomly assigned; players must click the matching bubble to score.
- **Timer Countdown:** Test your speed and reflexes within a limited time frame.
- **Score Tracking:** Keeps a live score of your correct clicks.

## 🛠️ Built With
- **HTML5** for structure
- **CSS3** for styling and layout
- **JavaScript (Vanilla)** for game logic and interactivity
